# 🇵🇹 Portuguese by Feinman

Веб-приложение для изучения португальского языка по **методу Фейнмана**:
если можешь объяснить тему просто, значит, ты её понял.

Каждая тема проходит четыре шага:

| Шаг | Что происходит |
|-----|----------------|
| **1. Изучи** | Короткая теория с примерами. |
| **2. Объясни** | Ты объясняешь тему своими словами. Приложение проверяет, какие ключевые идеи прозвучали, а какие нет. |
| **3. Найди пробелы** | Тест с разбором ошибок. Ошибки показывают, к чему вернуться. |
| **4. Упрости и повтори** | Своя аналогия плюс карточки с интервальным повторением (система Лейтнера: 1, 3, 7, 14, 30 дней). |

## Темы

- 👋 Приветствия и вежливость
- ⚖️ Ser и Estar — два глагола «быть»
- 🏷️ Род и артикли (o, a, um, uma, do, na…)
- 🗣️ Глаголы на -ar в настоящем времени
- 🔢 Числа 1–10
- 👄 Произношение (носовые звуки, lh, nh, ç, бразильские особенности)

## Запуск

Сборка и зависимости не нужны: это чистые HTML, CSS и JavaScript.

```bash
git clone https://github.com/<owner>/Portuguese-by-Feinman.git
cd Portuguese-by-Feinman
# просто откройте index.html в браузере или запустите локальный сервер:
python3 -m http.server 8000   # → http://localhost:8000
```

### Публикация на GitHub Pages

Откройте **Settings → Pages → Source: Deploy from a branch**, выберите ветку `main` и папку `/ (root)`.
(Для приватного репозитория на бесплатном тарифе Pages недоступен: сначала сделайте репозиторий публичным.)

## Структура

```
index.html        — оболочка страницы
css/styles.css    — стили (светлая и тёмная тема, адаптив под телефон)
js/lessons.js     — учебный контент: теория, ключевые идеи, тесты, карточки
js/app.js         — логика: роутинг, шаги Фейнмана, тесты, карточки, прогресс
```

Прогресс, объяснения и состояние карточек хранятся в `localStorage` браузера.

## Как добавить тему

Добавьте объект в массив `window.LESSONS` в `js/lessons.js`:

```js
{
  id: "my-topic",
  title: "Название",
  emoji: "📘",
  summary: "Коротко о теме",
  theory: ["Пункт теории (можно с <b>HTML</b>)", "..."],
  simple: "Образец простого объяснения / аналогии",
  keywords: [{ idea: "Ключевая идея", any: ["вариант1", "вариант2"] }],
  quiz: [{ q: "Вопрос", options: ["a", "b", "c"], answer: 0, why: "Пояснение" }],
  cards: [["português", "перевод"]]
}
```
